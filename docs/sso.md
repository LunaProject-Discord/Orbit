# シングルサインオン (OAuth 2.0 / OpenID Connect)

ほかのサービスのアカウント (IdP) で、Orbit にログインできるようにします。
登録は管理画面 (`/admin`) の「シングルサインオン」で行い、サーバーの再起動は要りません。
管理者アカウントのログインには使えません。

ここでのログインは Orbit 自体へのログインです。メールの送受信 (IMAP / SMTP) には、
これまでどおりメールアカウントの追加 (パスワードやアプリパスワード) が必要です。

## 登録の流れ

1. 管理画面の「シングルサインオン」に出ている **リダイレクト URI** (`https://<ドメイン>/oauth/sso`) を、
   IdP にアプリ (クライアント) を登録するときに指定します。すべての IdP で同じ URI です。
2. IdP が発行したクライアント ID とシークレットを、「追加」から入力します。
3. IdP の URL は次のどちらかです。
   - OpenID Connect に対応していれば、設定の URL (`…/.well-known/openid-configuration`)。保存時に読み込んで確かめます。
   - そうでなければ、認可・トークン・プロフィール (UserInfo) の 3 つの URL。
4. プロフィールの項目名 (ID・メールアドレス・名前) を、IdP の UserInfo の応答に合わせます。
   入れ子の項目は `a.b` と書きます。ID は利用者ごとに変わらない値にしてください。

## IdP ごとの設定

| 設定 | 内容 |
| --- | --- |
| Orbit のアカウントを自動で作る | 初めてログインした人の Orbit のアカウントを作る。ドメインで絞れる。 |
| メールアドレスを信頼する | 同じメールアドレスの利用者がいれば自動で結び付ける (下の注意を参照)。 |
| Orbit の 2 段階認証を省略する | IdP 側で 2 段階認証をしている場合に。 |
| メールアカウントの追加を案内する | 自動で作った人の初回ログイン後に案内を出す。 |
| 有効 | オフにするとログイン画面から消え、その方法ではログインできない。 |

### メールアドレスの自動の結び付け

他人のメールアドレスを先に登録しておき、本人のログインを横取りされないよう、次のときは結び付けません。

- IdP が `email_verified: false` を返したとき。
- Orbit の利用者のメールアドレスが未確認のとき。運用者のコマンド (`pnpm user:create`) と、
  メールアドレスを決めた招待で作った利用者は確認済みです。メールアドレスを決めない招待で登録した利用者は未確認です。

ID の項目名や IdP の URL のホストを変えると、結び付けは解除され、次のログインで結び付け直します。

## 安全のための決まり

- IdP の URL は `https://` だけ (`ALLOW_PRIVATE_MAIL_HOSTS=true` の開発環境では `http://` も可)。
  サーバーの内部ネットワークを指す URL は使えません。
- ログインの途中の値 (state) は暗号化し、PKCE と、ログインを始めた端末だけが持つ合言葉で照合します。
  ほかの人が始めたログインの続きを踏ませる攻撃や、アプリへ戻る URL の横取りを防ぎます。
- クライアントシークレットは暗号化して保存し、画面にも API の応答にも出しません。

## Mailcow の例 (未確認)

Mailcow の管理画面の「OAuth2 Apps」でアプリを追加し、リダイレクト URI を登録します。
Mailcow は OpenID Connect ではないので、URL は直接入力します。

| 項目 | 値 |
| --- | --- |
| 認可 URL | `https://<Mailcow>/oauth/authorize` |
| トークン URL | `https://<Mailcow>/oauth/token` |
| プロフィール URL | `https://<Mailcow>/oauth/profile` |
| スコープ | `profile` |

プロフィールの項目名 (ID・メールアドレス・名前) は、実際の Mailcow の応答で確かめていません。
ログインで「利用者の情報を受け取れませんでした」と出るときは、`/oauth/profile` の応答に合わせて変えてください。

## まだ無いもの

- 設定画面から、既存の利用者が自分で IdP のアカウントを結び付け・解除する機能。
- パスワードでのログインを止める設定と、復旧用のコマンド。
- 利用者を無効にする (全端末からログアウトさせる) 機能。
